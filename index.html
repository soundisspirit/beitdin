> why_it_exists

built for testing, comparing, and pipelining output from multiple perspectives, getting multi-angle responses from different models and role combinations. currently this support running 3 apis at once, but try also shuffle roles when you have run once and get more perspectives.

every time you click [ run ], the output is appended to the markdown document. you can shuffle roles and run again to accumulate multiple perspectives into a single downloadable .md file.
